# mj_repo_saas

**여러 GitHub 저장소를 하나의 프로젝트 카드로 정리하는 대시보드.**

프론트엔드, API 서버, 문서 저장소가 따로 있어도 한 프로젝트로 묶어, 무엇을 만드는지와 지금 어디까지 배포됐는지를 한눈에 확인하는 도구를 목표로 합니다.

> 프로젝트 상태: GitHub 계정의 저장소 목록과 GitHub·GitLab.com 저장소 통계를 조회하는 로컬 화면을 구현했습니다.

## 로컬 실행

Node.js 20 이상에서 `node server.mjs`를 실행한 뒤 [http://127.0.0.1:9090](http://127.0.0.1:9090)을 엽니다.

- `https://github.com/clevekim00`처럼 GitHub 프로필 주소를 입력하면 해당 계정이 소유한 공개 저장소 목록을 불러옵니다. 카드의 **상세 통계 불러오기**를 누르면 주간 커밋, Watch 수, 사용 언어 비율을 조회합니다.
- 비공개 GitHub 저장소를 보려면 **GitHub 토큰 (선택)**에 접근 권한이 있는 [fine-grained personal access token](https://github.com/settings/personal-access-tokens/new)을 입력하세요. 조회할 저장소에 **Metadata: Read-only** 권한을 부여하고, 커밋 통계를 보려면 **Contents: Read-only**도 부여하세요. 토큰은 입력란에만 유지되며 앱이 따로 저장하지 않습니다.
- GitHub 또는 공개 GitLab.com의 개별 저장소 주소를 입력하면 바로 상세 카드를 불러옵니다. 추가한 카드는 열린 페이지에서 유지됩니다.

## 첫 버전에서 할 수 있는 일 (계획)

1. 공개 GitHub 또는 GitLab.com 저장소 URL을 붙여넣고 카드를 만듭니다.
2. 관련 저장소를 한 카드로 묶고, 각 저장소의 역할과 프로젝트 설명을 편집합니다.
3. 상세보기를 펼쳐 사용자 흐름 또는 구성 요소 간 흐름을 확인하고, 저장소·릴리스·배포 링크로 이동합니다.
4. GitHub 릴리스, 저장소의 태그, 실제 배포 정보를 구분해 확인합니다. 근거가 없으면 **출시 확인 안 됨**으로 표시합니다.

예를 들어 한 카드에 프론트엔드·API·문서를 묶고, 프론트엔드는 **배포 링크**, API는 **GitHub 릴리스 v0.3.0**, 문서는 **문서 사이트**를 표시할 수 있습니다. 이 예시의 버전은 실제 출시를 뜻하지 않습니다.
