# mj_repo_saas

[한국어](../../README.md) · [English](../en/README.md) · [日本語](README.md) · [Español](../es/README.md) · [简体中文](../zh-CN/README.md)

**複数のGitHubリポジトリをプロジェクトカードにまとめるダッシュボード。**

フロントエンド、API、ドキュメントを一つのプロジェクトにまとめ、目的とデプロイの進捗を確認することを目指します。

> 現在はGitHubアカウントのリポジトリ一覧と、GitHub・GitLab.comの統計を取得するローカル画面を実装しています。

## ローカル実行

Node.js 20以降で、リポジトリのルートから実行します。

```sh
node server.mjs
```

画面上部で한국어・English・日本語・Español・简体中文を選べます。選択はブラウザーに保存され、メイン画面とAtlasで共有されます。リポジトリの説明とユーザー入力は原文で表示します。

- [Project Atlas](http://127.0.0.1:9090/atlas/)の `mj_repo_saas` カードで **プロジェクトの流れ・詳細 → グラフを拡大** を開きます。
- 他のGitHubリポジトリを取り込み、詳細を開くと保存済みグラフを表示するか、ローカルGraphify CLIで生成します。サーバーのPATHに `graphify` が必要です。デフォルトブランチの対応コードファイルを最大24個解析し、超過分は部分表示となります。
- Atlasの取り込みカードと生成グラフは、非公開リポジトリのデータも含めてブラウザーのローカルストレージに保存します。トークンは開いているページ内で保持します。ページを開き直して非公開グラフを再生成する場合は **Contents: Read-only** のトークンで再度取り込んでください。
- [メイン画面](http://127.0.0.1:9090/)のGitHubカードは再読み込み後も復元されます。同じブラウザーとオリジンの保存済みグラフを詳細で再利用します。
- `https://github.com/owner` のようなプロフィールURLで公開リポジトリを取得します。**詳細統計を読み込む**で週間コミット、Watch数、言語比率を取得します。
- 非公開リポジトリには **GitHubトークン（任意）** に [fine-grained personal access token](https://github.com/settings/personal-access-tokens/new) を入力します。対象リポジトリに **Metadata: Read-only**、コミットやGraphifyには **Contents: Read-only** も付与します。
- 個別のGitHubまたは公開GitLab.comリポジトリURLは詳細カードを直接取得します。GitLab.comカードは開いているページ内で保持します。

## 初期バージョンの予定

1. 公開GitHub・GitLab.comリポジトリURLからカードを作成します。
2. 関連リポジトリをまとめ、役割と説明を編集します。
3. ユーザーや構成要素の流れを開き、リポジトリ・リリース・デプロイ先に移動します。
4. GitHub Releases、タグ、デプロイの根拠を区別し、根拠がなければリリース未確認と表示します。

例えば一つのカードにフロントエンド・API・ドキュメントをまとめ、デプロイリンク・GitHub release v0.3.0・ドキュメントサイトを表示できます。このバージョンは説明用です。
