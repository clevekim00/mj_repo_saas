공개 저장소와 제품 출시는 별개예요. 확인되지 않은 버전이나 출시는 따로 표시했어요.

PROJECT ATLAS 프로젝트 상세는 각 카드에서 펼칠 수 있어요.

GitHub 저장소 가져오기

공개 저장소는 토큰 없이 가져올 수 있어요. 비공개 저장소는 읽기 권한이 있는 토큰이 필요해요.

토큰 발급 안내
  1. GitHub에서 Fine-grained personal access token 발급을 열어요.
  2. 저장소의 소유 계정과 가져올 저장소를 선택하고 Metadata: Read-only를 확인해요.
  3. Generate token을 누르고 표시된 토큰을 이 창에 붙여넣어요.
