저장소 대시보드

GitHub 또는 GitLab.com 저장소의 커밋 활동과 사용 언어를 확인하세요.

GitHub 토큰 발급 안내

공개 저장소는 토큰 없이 조회할 수 있습니다. 비공개 저장소를 조회하려면 앱이 GitHub에 읽기 권한을 증명할 수 있도록 Fine-grained personal access token을 입력하세요.

  1. GitHub 토큰 발급 페이지 (새 탭)에서 토큰 이름과 만료일을 설정합니다.
  2. Resource owner에서 저장소 소유 계정을 선택하고, Repository access에서 조회할 저장소를 선택합니다.
  3. Repository permissions에 Metadata: Read-only가 포함되어 있는지 확인합니다. 주간 커밋 통계도 보려면 Contents: Read-only를 추가합니다.
  4. Generate token을 누르고 표시된 토큰을 복사해 GitHub 토큰 입력창에 붙여넣습니다.
